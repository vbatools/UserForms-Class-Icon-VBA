# Библиотека значков для VBA UserForms

Обширная коллекция значков для приложений VBA UserForms с использованием шрифта Segoe MDL2 Assets. Эта библиотека предоставляет простой доступ к широкому спектру значков в стиле Microsoft, которые можно использовать в приложениях Excel VBA.

## Особенности

- Более 1300 значков в стиле Microsoft
- На базе шрифта Segoe MDL2 Assets
- Простой в использовании перечисляемый тип VBA для доступа к значкам
- Функции для получения символов, кодов и названий значков

## Установка

1. Импортируйте модуль `modIcon.bas` в ваш проект VBA
2. Убедитесь, что в вашей системе установлен шрифт Segoe MDL2 Assets (стандартный для Windows 10/11)

## Использование

### Основное использование

```vba
' Получить символ значка
Dim iconChar As String
iconChar = getIcon(icAccept) ' Возвращает значок галочки/принятия

' Получить код значка
Dim iconCode As Long
iconCode = getIconCode(icHeart) ' Возвращает код Unicode для значка сердца

' Получить название значка
Dim iconName As String
iconName = getIconName(icStar) ' Возвращает строковое название значка
```

### Использование значков в UserForms

```vba
' Установить значок в метку
Label1.Caption = getIcon(icAccept)
Label1.Font.Name = "Segoe MDL2 Assets"
Label1.Font.Size = 16

' Установить значок на кнопку
Button1.Caption = getIcon(icSave)
Button1.Font.Name = "Segoe MDL2 Assets"
```

## Доступные значки

Библиотека включает следующие категории значков:

- Значки действий (принять, отменить, сохранить, удалить и т.д.)
- Значки навигации (назад, вперед, домой и т.д.)
- Значки связи (почта, телефон, чат и т.д.)
- Медиа значки (воспроизведение, пауза, видео и т.д.)
- Значки документов (папка, файл, печать и т.д.)
- Значки настроек и системы
- И многие другие...

Полный список см. в перечислении `IconEnums` в файле `modIcon.bas`.

## Функции

- `getIcon(codIcon)` - Возвращает символ значка в виде строки
- `getIconCode(codIcon)` - Возвращает код Unicode значка
- `getIconName(codIcon)` - Возвращает название значка
- `getAllIconsArray()` - Возвращает массив со всеми доступными значками

## Требования

- Microsoft Excel с поддержкой VBA
- Шрифт Segoe MDL2 Assets (входит в состав Windows 10/11)
